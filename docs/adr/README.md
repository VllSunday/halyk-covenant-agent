# Решения по архитектуре

Здесь лежат решения, которые дорого менять: они определяют форму данных или
поведение всего пайплайна. Мелкие развилки внутри модулей сюда не попадают.

| | Решение |
|---|---|
| [0001](0001-llm-compiles-ir-code-computes.md) | Модель компилирует ковенант в IR, считает код |
| [0002](0002-money-as-int64-tiyn-and-decimal.md) | Деньги в тиынах целым числом — заменено 0007 |
| [0003](0003-clause-level-versioning.md) | Версионирование на уровне пункта, а не документа |
| [0004](0004-no-general-agent-framework.md) | Без агентных фреймворков |
| [0005](0005-evidence-from-calculation-rows.md) | Улика выбирается из строк, давших число |
| [0006](0006-reproducibility-and-cache-policy.md) | Воспроизводимость прогона и политика кэша |
| [0007](0007-currency-neutral-money.md) | Валюта носится вместе с суммой |
| [0008](0008-covenant-period-comes-from-outside.md) | Ковенантный период задаётся снаружи |
| [0009](0009-strict-run-instead-of-partial-answer.md) | Неполный ответ не сдаётся |
| [0010](0010-shared-content-addressed-cache.md) | Общий кэш по содержимому — уточняет 0006 |
| [0011](0011-tiered-model-routing.md) | Модель выбирается по сложности роли, Sol остаётся эскалацией |

Формат: контекст, решение, отвергнутые альтернативы, чем платим. Последний раздел
обязателен — решение без названной цены обычно означает, что цену не искали.
